# ugc-kits (Claude plugin)

Five skills that drive Eric's UGC pipeline on Windows. The code lives in the UGC repo
(`pipeline/`, `edl/`); these skills tell Claude how to operate it.

| Skill | Use it when |
|---|---|
| `ugc-pipeline` | running / debugging the whole flow, EDL contract, quality gate |
| `ugc-video-editing` | setting up STYLES.md, the Inbox + ledger, auto-edit, render check |
| `ugc-recording-to-review` | first cut from a recording or a cloned-voice track, review rounds, finals |
| `ugc-project-management` | approvals page, applying decisions, what's waiting on Eric |
| `ugc-motion-graphics` | lower-thirds / callouts / statement and number cards as EDL overlays |

Install: see the UGC repo `docs/kit-integration.md` (one-tap steps).
