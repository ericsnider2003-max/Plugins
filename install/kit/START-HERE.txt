usage-max @VERSION@ - START HERE
================================
It keeps your Claude and Codex plans lasting until their weekly reset, automatically.

FIRST: right-click this zip and choose "Extract All". Files run from inside the zip window cannot find
their neighbours.

PICK WHAT YOU USE (you can do more than one)

 A) Claude DESKTOP APP / claude.ai / cloud sessions (the ones with the cloud icon)
    Easiest, no upload: put usage-max in the REPO the sessions run on. Sessions on the "Plugins" repo already
    have it (its .claude/settings.json is committed). For any other repo, run this once in a terminal inside
    that repo and commit the file it writes:   usage-max enable-here     (from Claude Code: /usage-max enable-here)
    Every new session on that repo then loads usage-max by itself and updates itself.
    Alternative (works for any session, and for Cowork): Settings > Plugins > Your plugins: remove the old
    "usage-max", choose "Upload local plugin" and pick  usage-max-plugin-@VERSION@.zip  (in this folder).
    An upload does not update itself; 3-CHECK-EVERYTHING tells you when a newer version exists.
    Always start a NEW session afterwards: a session keeps the plugin list it started with.
    What it does in the cloud: routing rules, the Sonnet cap on subagents, short replies. It cannot see your plan
    percentage there and forgets everything between sessions, so plan tracking lives on your PC (part B).
    Your weekly percentage is account-wide, so the PC reading covers cloud and chat use too.

 B) Claude Code in a TERMINAL on your PC (this is where plan tracking runs)
    Run 1-INSTALL-CLAUDE. It installs from GitHub and updates itself. Open a NEW session, type /usage-max.
    4-CALIBRATE-CLAUDE is only for this PC, and only needed if the status line shows no "wk NN%".

 C) Codex (app and CLI)
      1. Remove the OLD usage-max from the Codex plugin list if it is there (it runs Claude-only hooks inside Codex).
      2. Run 2-INSTALL-CODEX.
      3. In the Codex CLI window type  /hooks  and trust the usage-max hooks. (The Codex app cannot open
         /hooks; the trust is saved in your Codex config and is shared.)

THEN: run 3-CHECK-EVERYTHING any time. Lines starting with FIX say exactly what to do.

Biggest saving to do once: type  /usage-max diet  in Claude. It lists the plugins that add the most
tokens to every session (about 40,000 on your setup) and prints the command to turn off the ones you never use.
